# Low-Light Image Enhancement

A low-light image enhancement project developed for the NTIRE 2026 Challenge — Track 1, focused on improving visibility, brightness, and perceptual quality of dark images using image processing and deep learning techniques.

## Dataset
NTIRE 2026 Low-Light Enhancement Dataset

## Model / Approach
- Image enhancement and restoration pipeline
- Brightness and contrast enhancement
- Noise reduction and detail preservation
- Validation and evaluation of enhanced outputs

## Features
- Low-light image enhancement
- Noise reduction
- Contrast improvement
- Image quality evaluation
